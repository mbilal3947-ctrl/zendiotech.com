# Zendiotech — Rebuilt Website

## Architecture
- Seven connected HTML pages.
- One shared `css/global.css` design system.
- One responsive `css/responsive.css` layer.
- One shared `js/main.js`.
- Exact supplied Zendiotech logo in `assets/logo/zendiotech-logo.png`.

## Included
- Consistent global header and footer.
- Complete navigation across Home, About, Services, Industries, How We Work, Roadmap and Contact.
- Arabic UI toggle.
- Scroll reveal animations.
- CSS 3D/orbital technology visuals.
- Pointer-based 3D tilt and hero parallax.
- Responsive desktop/tablet/mobile layouts.
- Existing page content retained and consolidated into the global system.
- Front-end contact form validation/confirmation.
- Favicon, robots.txt and sitemap.xml placeholders.

## Test
Open the folder in VS Code and run `index.html` with Live Server.

The contact form intentionally does not send data anywhere until a secure backend/form provider is connected.
Replace `zendiotech.com` in robots.txt and sitemap.xml when the production domain is confirmed.
